# Credit Card Customer and Transaction Report
                                                            
# Project Overview
As part of this task, I required to build two
interactive Power BI dashboards from the provided
datasets. The dashboards should provide actionable
insights and be filtered by gender (Male/Female). The
primary focus is to create meaningful visualizations
based on key metrics related to Credit Card
Customers and Credit Card Transactions.

This Power BI dashboard analyzes customer demographics, loan adoption patterns, transaction behavior, and credit card performance to derive actionable business insights.
Project Objective
# Tools Used
- Power BI
- DAX
- Data Modeling 
- Data Visualization
# Dashboard 1: Credit Card Customer Report
- 10K Total Customers
- 1,310 Loan Customers
- Average Income Analysis
- Customer Segmentation by Education & Marital Status
# Key Insights:
- Married customers form the largest segment.
- Businessman category has highest average income.
- Loan adoption is relatively low compared to total customer base.
# Dashboard 2: Credit Card Transaction Report
- 667K Total Transactions
- 46M Total Transaction Volume
- Q4 shows highest transaction growth.
- Blue Card category dominates transaction volume.
# Key Insights:
- Transaction spike observed in Q4.
- Chip usage is the most preferred transaction method.
- Interest earnings consistent across quarters.
# Business Value
- This dashboard helps financial institutions:
- Identify high-value customers
- Monitor credit risk exposure
- Analyze seasonal transaction trends
- Support strategic decision-making
